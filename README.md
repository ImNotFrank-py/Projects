# Projects I contributed to or made myself

  # Project 1: RPG Style Tower Progression Game (Team Project)
     - A progressive RPG tower style game where the player choses a class, answer riddles to fight enemies with different elemental attributes, and attempt to clear all five (5) floors including the boss floor.
  # My Contributions: 
     - Made use of OOP (Object-Oriented Programming), Inheritence, Interface, File handling 
     - Developing the parent class "Character.java" and the child classes "Enemy.java", "Warrior.java", "Mage.java", "Assassin.java", and "Paladin.java" to allow for child classes to extend off of the parent and prevent repetitive code.
     - Developed the "Damageable.java" interface which defined the damage and health for the player and enemy.
     - Developed the logic behind the game's element system. This element system would affect the player's gameplay by making it harder or easier, due to the enemies having a randomized elements which led to the player having an advantage, disadvantage or neutral typing.
     - Developed the file output system "datalog.txt" to allow for data tracking whenever the player completed a playthrough of the game. At the moment, it only outputs the player's selected class, floors completed, and if they won or loss.
